# Glossary

> Unifies project terminology. **When the AI generates/regenerates code and writes documents, naming and wording follow this glossary**, ensuring consistency across documents and across regenerations.
> This is especially important for "regenerating code from documents": consistent wording makes regeneration results stable.
> Add a new row whenever an important new term appears.
